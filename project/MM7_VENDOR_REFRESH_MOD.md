# MM7 vendor refresh on entry

The Atlas may opt an MM7 private-mod launch into `ENROTH_MM7_VENDOR_REFRESH_ON_ENTRY=1`. The engine accepts the exact value `1` only for MM7. The normal game and other titles retain their existing refresh schedule.

After a successful house entry creates a new window, weapon, armor, magic-item and alchemy shops regenerate both standard and special stock once. Magic guilds regenerate their spellbooks once. The next refresh deadline is set using the house's normal generation interval, so opening another buying submenu during the same visit does not reroll again. Closed and banned shops do not create a house window, and non-vendor houses have no refresh hook. Existing submenu refresh behavior remains the fallback when the mod is off.

The per-window guard is checked by two linked synthetic unit tests for an exact opt-in, one refresh per visit, a fresh refresh on the next visit, and MM6 title isolation. The focused MM6/MM7 vendor test set passed 16/16 and non-MM6 unit controls passed 440/440 after integration. A mod-enabled MM7 headless save/load smoke passed 1/1. Two further headless game tests entered a real MM7 weapon shop and magic guild with a future stock deadline and sentinel values; both regenerated on entry, and switching to Buy did not regenerate again (2/2). The monitor observed no on-screen window or focus change. The signed Atlas and engine bundle was installed locally. The prior bundle was then kept as a private backup, which the 2026-11-22 app replacement policy in `AGENTS.md` superseded: superseded apps are now deleted. A visible play-session shop check remains open. Superseded 2026-11-23: the Atlas vendor toggle now also sets `mods.mm6.vendorRefreshOnEntry` and passes `ENROTH_MM6_VENDOR_REFRESH_ON_ENTRY` to the MM6 helper (`launcher/GameBuild.swift`), which reads it in `src/Engine/MM6/MM6ShopRefreshBoundary.cpp`.

No game assets or private mod files are part of this change. The environment variable is supplied at launch rather than serialized into saves, so turning the mod off restores the normal scheduling rule for subsequent visits.
