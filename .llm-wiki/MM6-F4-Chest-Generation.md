# MM6 F4 Chest Generation

The [public audit](../project/MM6_F4_CHEST_GENERATION_AUDIT.md) records the live-load chest gate. Retained F3-backed map data contain 943 random-item markers across six MM6 negative IDs; the save validator accepts them as references, not generated items. `Engine::_461103_load_level_sub()` now routes through a title guard: MM6 throws before inherited chest/RNG/artifact mutation, MM7 retains the existing `GenerateItemsInChest()` path. The inherited artifact picker points at MM6 message-scroll IDs. A later [original-executable save-path trace](MM6-F4-Chest-Grid-Wire.md) proves the full 140-cell signed grid wire; live projection and persistence remain unproved. **Every MM6 level load reaching this call is blocked**, including marker-free maps, until a generator or proved skip policy exists.

A verified owner-local PE trace now locates the outer generator, MM6-specific remap table, item picker, two artifact paths and chest placement call chain. The remap table is encoded in a detached tested helper; **the live guard remains closed**. The outer generator consumes an RNG draw even on marker-free maps; first-attempt probability can carry between markers. The item picker branches over MM6 1–399 regular templates and 400–429 tier-6 artifacts, then potion/wand/enchantment fields. The distinct direct tier-7 picker includes candidate 430 and has an unsafe slot-index mark write; see the [direct artifact audit](MM6-F4-Chest-Direct-Artifact.md). Placement calls separate fit/finalize helpers. Next agents should read the ignored private packet `local-game-data/private-wiki/mm6/F4_CHEST_PE_TRACE_2026-11-06.md` and bounded disassembly under `local-game-data/mm6/research-2026-11-06/`. Complete the nested RNG/field and placement contracts, then test all six active markers, artifact state, full chests and save/reload before lifting the guard. MM7 must keep its own generator. Do not treat map-item validation or one successful chest opening as generation closure.

The first detached stage, `mm6::pickChestBaseItemId`, models the **ANY base-ID stage only**. It preserves the original 15-bit RNG, unconditional artifact-candidate draw, tier-6 5%/13-cap trial, and the zero-remainder choice of item 1 even at a zero-weight tier. Six retained `rnditems.txt` weight sums match the expected bounded 1–399 domain. Seeded tests cover artifact success/fallback, original weighted boundaries and MM7 rejection. It does not construct an item or publish state.

The second detached stage, `mm6::finalizeChestAnyItem`, models only field writes made by that original **ANY picker** after base selection. It sets the identification flag from the template, draws weapon/equipment enchantment chance and weighted fields as eligible, and sets wand current charges from the template byte plus `RNG % 6`. A plain potion gains no power and consumes no additional draw at this stage; chest placement and other item sources require separate tracing. Standard attribute remainder zero can choose a zero-weight first attribute. Tier-six artifact success exits without regular field writes. Caller rows are preflighted, and the function returns staged fields/flags/RNG without publishing state. Seeded native tests cover these branches and malformed rows. The private packet records exact PE branch evidence. The live chest guard stays closed until original 28-byte item construction, placement, live grid projection and save/reload are proved.

The [placement follow-up](MM6-F4-Chest-Placement.md) establishes the original **in-memory** 140-cell signed grid and a detached seeded first-placement model with fit, no-fit and wand fallback. Retained baseline delta grids are all zero, so changed-state save equivalence and integration remain open. The live MM6 guard is unchanged.

The detached `MM6ChestCallerAdapter` now fills those caller rows from an MM6-initialized `ItemTable`, using 399 tier weights, the selected template, six chance/strength rows, fourteen standard weights and fifty-nine special rows. It keeps the MM6 equipment special chance separate from the MM7 cumulative field convention. A separate source selector distinguishes empty, gold, ANY and direct tier-seven artifact routes; gold stages one draw and title-specific IDs. The direct artifact path now has a bounded trace model and a separate explicit safe 30-ID policy option, neither wired live because the original ownership scan is unsafe and gameplay/save policy is unresolved. An ignored F3-matched numeric profile drove 192 seeded ANY stages across six tiers in native tests, all passing. No live chest generation was enabled.
