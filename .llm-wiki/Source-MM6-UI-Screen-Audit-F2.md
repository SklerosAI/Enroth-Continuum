# MM6 UI Screen Audit F2 Source

The [screen audit](../project/MM6_UI_SCREEN_AUDIT_F2.md) inventories the named C++ screen IDs and groups them by menu, world, party, book, dialogue, service, save and ending consumers. It supplies an F5 visual and interaction scenario for each named family. This is source coverage, not proof of an original MM6 layout or a usable screen.

The current load menu accepts `.mm7` and `SaveGameLite_MM7`. The world hover path uses an MM7 decoration-topic base; the character paperdoll retains MM6-artifact branches that assert if reached. The winner path selects MM7 good/evil text and writes an MM7-named capture. F3 must reconcile original MM6 resources and IDs; F4 must make the consumers title-aware; F5 must view the screens and durable state changes. Reserved enum IDs need call-site classification before they are assigned MM6 meaning.
