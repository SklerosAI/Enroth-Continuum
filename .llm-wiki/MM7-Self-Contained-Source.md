# MM7 Self-Contained Source

The [source-autonomy packet](../project/MM7_SELF_CONTAINED_SOURCE.md) tracks the remaining MM7 cutover after a clean tracked-source Mac build passed under network denial; see the [verified build page](MM7-Clean-Offline-Build.md). The MM7-only `codex/mm7-public-preview` branch is on the SklerosAI remote at `d76afb519`, based on its public MM7 baseline without the integration branch's MM6 research history.

The current Atlas helper already comes from this fork's MM7 source, but an unqualified CMake build may download OpenEnroth-hosted prebuilt dependencies. The [local arm64 build-input inventory](../project/MM7_SELF_CONTAINED_BUILD_INVENTORY.md) recorded one 21.7 MB archive with nine linked static libraries, 23 original gitlinks (about 126 MiB of checked-out trees), and seven cached nested source checkouts. Pinned `generator`, `fast_float`, `magic_enum`, `mio`, `small_vector`, `cmrc`, `cli11`, `fmt`, `spdlog`, `sol2`, GoogleTest, `gtest_parallel`, `luajit-cmake`, LuaJIT, Boost.Lambda2, cpptrace, cpplint, GLM and Dear ImGui sources are now tracked here with full licenses and provenance, leaving one external ztd.text gitlink. GoogleTest and `gtest_parallel` are optional test inputs. The owned LuaJIT source and CMake recipe now generate the same version header without nested Git. The first sixteen snapshots passed standalone checks; all nineteen now pass a cached-input arm64 MM7 link. The latest three also passed exact Git blob/mode comparison and focused C++/Python syntax checks. The normal `CMakeModules/Git.cmake` path runs a recursive submodule update, cpptrace fetches a pinned libdwarf-lite commit, and ztd.text fetches six floating `main` branches. The prebuilt ZIP has no complete source/license manifest or expected hash in the CMake download rule; ztd-family license wording and FFmpeg build terms need review before copying. The inventory is local evidence, not an offline-clone test.

An opt-in `EC_LOCAL_ONLY_CONFIGURE=ON` gate now skips the recursive submodule update, forbids the OpenEnroth dependency archive, disconnects nested FetchContent and fails with named missing repository-owned inputs. A fresh arm64 AppleClang configure reached that refusal without a download; focused fake-Git and archive-guard checks passed. The gate now validates and links the local library prefix, uses tracked libdwarf and a scoped Mac iconv adapter, and passed the clean tracked-source build. The ordinary CMake lane still has upstream routes. The ordinary CMake configure path and installed helper remain unchanged. The dedicated Mac MM7 wrapper selects the proven local-only path automatically.

Boost.Lambda2's exact pinned files identify the Boost Software License but did not include its full text. The repository adds an unmodified copy from [Boost's official license page](https://www.boost.org/LICENSE_1_0.txt) as separately marked metadata, with the source URL and hash in its provenance file. The integration cached-input MM7 target still builds.

The owned cpptrace snapshot includes its MIT license. Its exact pinned LGPL libdwarf-lite backend source is now tracked here with original notices. A standalone arm64 cpptrace/libdwarf build passed using that local source with FetchContent disconnected. The local-only integration CMake route now pins this source; the clean MM7 target built with FetchContent disconnected.

The five source families behind the Mac prebuilt archive are now ordinary tracked files under [`thirdparty/repo-source/`](../thirdparty/repo-source/README.md), at the dependency tag's exact commit pins. [`SOURCES.json`](../thirdparty/repo-source/SOURCES.json) records source URLs, archive hashes and primary license files; all 11,835 regular archive files matched the extracted bytes. Inherited ignore rules initially omitted 84 files, which were force-added, and Git attributes prevent line-ending normalization. An original [local recipe](MM7-Mac-Dependency-Recipe.md) has since built all nine arm64 archives from these sources, copied notices and checked FFmpeg's effective license-mode flags. The local-only MM7 target now links this recipe output; a headless control passed after the clean build. Binary distribution review remains open.

Scoped production headers and required CMake files from pinned inifile-cpp, tcpp and nlohmann/json are also tracked with licenses and provenance, replacing three more gitlinks. All 72 copied upstream files matched pinned Git blobs. The cached-library MM7 link, 12 focused JSON/preprocessor units and a headless MM7 control passed. Their upstream test-only Catch2 and GPL files were not copied. Only the ztd.text gitlink remains for ordinary builds. An original Apple iconv adapter now serves the opt-in Mac MM7 lane and passed its scoped build and headless control; full legacy/CJK API parity remains open.

The [upstream dependency release](https://api.github.com/repos/OpenEnroth/OpenEnroth_Dependencies/releases/tags/deps_r8_master) publishes a size and SHA-256 that match this Mac's cached arm64 ZIP. Its [pinned tag](https://api.github.com/repos/OpenEnroth/OpenEnroth_Dependencies/git/refs/tags/deps_r8_master) and [tree](https://api.github.com/repos/OpenEnroth/OpenEnroth_Dependencies/git/trees/866c037e528bb38ee286874f107fb488dd9fb354?recursive=1) identify exact FFmpeg, libpng, OpenAL Soft, SDL and zlib-ng revisions; the build script gives a recipe starting point. The [inventory](../project/MM7_SELF_CONTAINED_BUILD_INVENTORY.md) records those pins. They informed an original repository-owned recipe, which built the five source families in an isolated arm64 prefix. The upstream recipe repository lacks a top-level license, so its script was not copied.

The pinned source audit now records each family's primary license file and additional bundled-component notices in the inventory. FFmpeg's cached archives embed the tagged recipe's GPL/version3/nonfree disables and report LGPL-2.1-or-later, but the recipe permits automatic external-library detection and the archive lacks `config.h` or a build log. The new local recipe disables autodetection, checks generated FFmpeg license-mode flags and copies source notices. Its MM7 link and bounded headless runtime passed; visible play/save and binary distribution review remain open.

Atlas and direct Mac helper source now default MM7 data and user paths to private Enroth Continuum roots, with Vault and transfer-path access on the fresh profile. The new private data root holds a byte-verified copy of extracted MM7 data, and a headless control passes through that default. The [runtime path cutover](MM7-Runtime-Path-Cutover.md) requires separate private backups and collision review before moving saves or switching the installed app. Legacy locations remain rollback sources; neither game data nor saves enter Git.

The dedicated [`tools/build_mm7_macos.py`](../tools/build_mm7_macos.py) command now builds and stages the Mac MM7 helper from tracked source without an upstream fetch. A fresh tracked-source extraction ran that command end to end under network denial, with valid app versions, codesign and system-only dynamic links. The next route is to preserve OpenEnroth credit, repeat the build from a remote clone, finish visible launch/save/reload from explicit private paths, then decide whether to switch the ordinary shared CMake defaults after MM6/MM8 and non-Mac regression checks. Completion requires the fresh-clone build to use no OpenEnroth checkout, dependency release, submodule origin, build-time URL or local dependency cache. Original GOG data and saves stay private and outside Git. The Apple SDK remains an external system input.

The one-command Mac MM7 build route is proven from a clean extraction of the published preview, while a separate remote clone, shared CMake defaults and installed-app migration remain incomplete. An optional `upstream` remote remains only for deliberate review of later source changes; OpenEnroth history, license, notices and authorship remain in the fork. Do not replace the known-good installed MM7 helper before the new build passes its play and save checks, and do not describe a cached local build as a clean offline build.

The owner reaffirmed this as a required eventual MM7 finish line. The gate now
also calls for an audit of user-facing app identity, bundle metadata, Atlas
text, CLI defaults and local config/cache/log paths, so the installed helper
uses Enroth Continuum/MM7 identity and private paths throughout. Historical
OpenEnroth links and authorship remain in credits and source provenance;
internal inherited symbol names can be migrated separately when safe.
