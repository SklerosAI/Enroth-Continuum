Pinned `generator`, `fast_float`, `magic_enum`, `mio`, `small_vector`, `cmrc`, `cli11`, `fmt`, `spdlog`, `sol2`, GoogleTest, `gtest_parallel`, `luajit-cmake`, LuaJIT, Boost.Lambda2, cpptrace, cpplint, GLM and Dear ImGui are now tracked here, leaving 4 gitlinks. ## Current boundary

The `MM7` target and Atlas helper are compiled from Enroth Continuum's own forked source. Atlas stages an explicitly supplied, title-locked `MM7.app`; it does not download or run an OpenEnroth release binary. OpenEnroth's Git history, LGPL license, notices and contributor credit remain part of the fork.

A clean Mac build is not yet self-contained. The normal configure path can still download a versioned archive from `OpenEnroth/OpenEnroth_Dependencies`, update 4 externally hosted Git submodules, and fetch nested cpptrace/ztd.text sources. Cached local dependencies hide those requirements on this Mac. Nineteen pinned, license-preserving third-party snapshots are now repository-owned. The first sixteen passed standalone network-disconnected checks; all nineteen passed a cached-input arm64 MM7 link after integration, and the latest three also passed exact-blob and focused syntax checks. GoogleTest and `gtest_parallel` are optional test inputs, not MM7 app runtime libraries. The owned LuaJIT source and CMake recipe now generate the same version header without a nested Git repository. The new opt-in `EC_LOCAL_ONLY_CONFIGURE=ON` path blocks the remaining configure-time network routes, defaults prebuilt dependencies off and fails with named missing repository-owned inputs; it deliberately refuses even when source directories are present until local source-build recipes are connected. A fresh arm64 AppleClang configure reached that named refusal without a download. It is a migration scaffold, not a successful offline build. The Atlas and direct Mac helper source now default to Enroth Continuum MM7 data and a fresh profile, including Vault and transfer-path access; the installed app has not been switched, and a saved data preference may still explicitly point elsewhere. See the [runtime path cutover](MM7_RUNTIME_PATH_CUTOVER.md). The upstream Git remote is optional for reviewed synchronization; it is not a runtime input.

The owned top-level cpptrace snapshot includes its MIT license, but its current Mac symbol backend still fetches pinned LGPL libdwarf-lite source. A standalone alternate-backend cpptrace build passed; that does not prove the production backend can build offline. The cached-input integration MM7 target linked after all nineteen source conversions.

The upstream dependency release now supplies an official digest matching this Mac's cached arm64 ZIP, and its tagged Git tree pins the five source families behind the nine prebuilt archives. The [inventory](MM7_SELF_CONTAINED_BUILD_INVENTORY.md) records the exact commits and build-script reference. All five commit archives were extracted as ordinary tracked source files; a comparison checked every one of their 11,835 regular files against the downloaded archive, and Git attributes prevent line-ending normalization. Repository-owned build recipes, notice packaging and FFmpeg's effective build configuration still need review. Do not copy the upstream dependency script: its repository has no top-level license.

The exact pinned source-license audit identified primary licenses and bundled-component notices, but no replacement recipe was committed. The cached FFmpeg archives report LGPL-2.1-or-later and the tagged build disables GPL, version-3 and nonfree features. Its recipe still allows automatic external-library detection and the ZIP lacks a configuration log, so a new source build must pin and verify its effective feature set and distribution notices before it can replace the cached archives. The new source snapshots do not change the installed MM7 app or authorize distribution of the cached binary archive.

## Migration gate

1. Freeze the working MM7 source revision, installed helper, save/profile backup and build hashes. Keep Atlas pointed at the known-good helper until the replacement passes launch and save/load checks.
2. Record each Mac MM7 build input, exact revision/hash, license, current fetch path, size and whether it is required at runtime. Keep original Might & Magic game data and saves outside Git.
3. Replace OpenEnroth-hosted prebuilt dependency downloads with reproducible source builds from pinned, license-preserving inputs held in this repository. Replace required Mac-build submodule/fetch-at-configure dependencies with repository-owned source snapshots. Do not remove upstream copyright files or flatten authorship without a traceable provenance record.
4. The opt-in local-only configure gate now fails clearly on missing inputs and refuses cached/system-library substitution. Connect pinned repository-owned build recipes, then produce arm64 `MM7.app` and stage Atlas from a clean SklerosAI checkout while offline, using the installed Apple toolchain/SDK.
5. Check the app's title lock, notices and library links, then launch MM7 through Atlas, load an existing save, save again, quit and reload. Confirm the MM6/MM8 sibling slots and private profiles remain untouched.
6. Atlas and direct Mac helper source now use explicit private Enroth Continuum MM7 data and fresh profile defaults, including Vault and transfer paths. Before switching the installed app, copy and hash-check the owner's existing data and distinct save roots locally under the [collision-safe cutover](MM7_RUNTIME_PATH_CUTOVER.md); retain legacy roots for rollback. Do not put proprietary files or saves in Git.
7. Audit the installed app's user-facing name, bundle metadata, Atlas text, CLI defaults, configuration, caches, logs and save paths. Present the finished Mac helper as Enroth Continuum/MM7 and migrate inherited OpenEnroth runtime locations without losing existing saves. Keep historical OpenEnroth names in attribution and provenance; internal source identifiers can be renamed separately when safe.

The completion claim means a fresh clone can configure, compile and package the **Mac MM7 engine and its required non-system build inputs** with networking disabled, without an OpenEnroth checkout, release archive, submodule origin or build-time URL. Atlas and MM7 use Enroth Continuum's explicit private data/profile paths for launch, saves and transfer. A retained `upstream` Git remote may still be used deliberately to review later changes; it is not consulted by the build or runtime. The Apple toolchain/SDK and the owner's lawfully obtained GOG game files remain external by design. OpenEnroth history, license, notices and contributor credit remain permanent provenance, not build dependencies.
