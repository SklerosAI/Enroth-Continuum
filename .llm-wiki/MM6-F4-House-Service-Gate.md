# MM6 F4 House Service Gate

The [F4 packet](../project/MM6_F4_HOUSE_SERVICE_GATE.md) explains the title-specific entry gate and the retained house-type/range audit. The MM6 classifier records shop, magic-guild, stable/boat and other families without indexing MM7 house-ID arrays. All MM6 house entry still rejects before inherited room media, shop timers, NPC mutation or service windows. MM7 keeps its current path.

The ignored format-2 house-route report keeps exact row/event IDs and hashes. The next agent needs the MM6 room descriptor table, title-specific stock keys and refresh state, service windows and offline event-to-house scenarios before narrowing this gate. A parser category or an in-range room ID does not prove a working house.

The [read-only service data packet](../project/MM6_F4_HOUSE_SERVICE_DATA.md) preserves MM6 column `A` stock/skill text and column `C` route/arena notes separately from MM7 numeric pricing fields. It joins all 557 retained table rows to validated room descriptors or explicit blank-room dispositions and checks the service-family counts. Four focused house data/room tests pass with private retained inputs. Stock, prices, hours, service windows and persistence still need title-specific rules before entry is enabled.

The [transport menu packet](../project/MM6_F4_HOUSE_TRANSPORT_MENU.md) joins all 21 stable/boat service rows to the private 21-house route manifest and validated MM6 room descriptors. A pure three-slot selector exposes only scheduled, weekday-valid, nonquest routes while departure and house entry remain guarded. The weekday input, fare, quest policy, autosave and visible travel still require proof.
