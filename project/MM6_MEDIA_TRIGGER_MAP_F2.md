## Event movie ambiguity

The active `.evt` scan found **12** opcode-12 records and **215** opcode-11 records whose candidate strings all exist in the retained bitmap index (earlier [media closure](MM6_MEDIA_F2_CLOSURE.md)). The current MM7 interpreter labels opcode 12 `EVENT_ShowMovie` and calls `PlayFullscreenMovie()` ([source](../src/Engine/Evt/EvtInterpreter.cpp#L299)), while the current parser expects its MM7 movie payload shape ([source](../src/Engine/Evt/EvtInstruction.cpp#L966)). The MM6 [opcode semantics packet](MM6_OPCODE_SEMANTICS_F2.md) instead identifies the observed MM6 opcode-12 shape as an outdoor texture operation. **Do not count these 12 records as MM6 movie triggers.** F3 must establish the actual MM6 event movie opcode and payload from original bytes/independent semantics, then enumerate active movie calls. The present static movie trigger set consists only of six current C++ literals; house movie trigger IDs remain unmapped until the MM6 descriptor join.
