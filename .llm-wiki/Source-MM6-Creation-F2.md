# MM6 Creation F2 Source

The [creation audit](../project/MM6_CREATION_F2.md) and tracked [rules probe](../scripts/mm6_probe_creation_rules.py) join the owner's creation instructions, retained MM6 class/item/spell indexes and current C++ startup. The inherited party default includes an MM7 Thief and MM7-only skills; the creation screen offers inherited class buttons and portrait/voice arrays. The documented MM6 Create Party and Quick Start routes do not exist as distinct engine paths. `GameStarterOptions.quickStart` only skips slow initialization and is not the game's Quick Start.

The inherited completion block requests seven starter spellbook literals outside MM6's retained spellbook band; its bottle constant classifies as an MM6 spell scroll. These are source/category collisions, so current startup grants cannot define MM6's intended initial inventory. Exact class starting vectors, legal optional skills, Quick Start composition, starting gear, spellbooks and portrait/voice mappings still need original evidence and live acceptance. A primary reference gives starting-array schemas but not the values. No original archive was reopened and no MM6 creation route was verified in play by this audit.

The later [creation-constants packet](../project/MM6_CREATION_CONSTANTS_F2.md) pins candidate MM6 process addresses and shapes for six HP/SP bases, 18 promoted factors, six by seven starting stats, six by 31 starting-skill codes and 13 skill-recovery entries. It also traces retained Cleric class ID 3 to an inherited Black Knight/no-mana branch. These are source leads and an ID collision, not verified owner-executable values or visible HP/SP behavior. The guarded F3 PE helper has passed synthetic mapping tests and still refuses while F2 is open.
