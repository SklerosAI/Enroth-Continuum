# MM6 `SHOP` owner field gate — F4

Status, 2026-11-06: a detached, raw physical `SHOP` section preserves the original contiguous stock region, and a title-local process owner can stage it together with `SCLK`. **No `SHOP` field is safe to add to the required known-save manifest or live `.ec6` transaction**. The only joined shop/guild save field is the keyed 64-bit refresh deadline encoded in required `SCLK` v1. Normal MM6 SaveLoad and house services remain guarded.

## Evidence and decision

The accepted original-executable trace and retained 557-row house matrix establish the active house row as the stock and refresh key. Shop rows 1–47 and spell-guild rows 119–140 have proved refresh-deadline reads/writes; the final shop and first guild address the same physical deadline word. `ShopGuildClockFields` preserves those **68 distinct words**, tests nonzero round-trip and rejects late truncation without mutating its destination. This is a complete bounded field, already implemented; adding a second copy under `SHOP` would create two authorities for one physical word.

The keyed index and detached purchase/refresh helpers preserve these facts. | The [item conversion audit](MM6_F4_SHOP_ITEM_RECORD_CONVERSION_GATE.md) identifies MM6 fields but leaves MM7 category/flag equivalence and the raw tail unproved. The fork has no MM6-keyed runtime owner or service writer to keep an opaque record current. |
| Ban, in-shop or bounty tuple | The inherited MM7 code has analogous state families. | Its `HouseId` intervals do not identify MM6 spell guilds or candidate town halls. Original MM6 row keys, widths, lifetime and write semantics for these fields are unproved. |

The existing partial session coordinator intentionally rejects nonempty inherited MM7-indexed shop/guild/bounty arrays. The source-proven stock address formulas have a title-explicit physical-record-index helper: bank one and bank two accept shop rows 1–47 and positions 0–11; guild rows 119–140 share the second bank's final-shop 12 positions. A detached purchase helper models full-record transfer and the original partial source clear. `ShopStockFields` allocates one raw 1,440-record physical array and can round-trip it as isolated `SHOP` v1. The new `ShopTitleState` is a process-local aggregate of that physical image and the 68 deadline words. It starts unready, creates an explicit empty New Game seed, and stages both required raw sections before a no-throw owner publication. It has no live Party capture or service writer. The integrated linked stock/clock/owner suite passed **13/13** with nonzero shared-row/tail and clock staging, wrong-title rejection and late `SHOP`/`SCLK` failure leaving the prior owner intact. The [purchase-write follow-up](MM6_F4_SHOP_PURCHASE_WRITE_GATE.md) also records an independent editor layout that starts the guild list one physical row later than the original active guild address. Therefore **no required `SHOP` section, provisional item-ID field or MM7 array adapter is added**.
