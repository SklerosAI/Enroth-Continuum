This packet does not complete the full [F3 matrix](MM6_F3_PREFLIGHT_MATRIX.md), begin F4, or claim playable MM6. Original GOG files were read only from the owner's local installation; exact filenames, member offsets, hashes, decoded bytes and per-file decisions remain Git ignored in `local-game-data/mm6/research-2026-11-05/F3_CONTENT_RECONCILIATION_2026-11-05.json` and `F3_CONTENT_SCHEMA_SIGNOFF_2026-11-05.json`. The private reproduction script there has the source method. No MM6 process was launched or MM7/MM8 path changed.

## Method and provenance

The gated F3 identity report matched the checked core files and soundtrack tracks to the frozen F1 snapshot; the bounded capture reported no directory/name/size/hash discrepancy. This lane reread only the original `icons.lod` and `Games.lod` during the same F3 session, rechecked their whole-file hashes against the private ledgers, then extracted selected members through bounded offsets. It applied the current fork's MM6 compressed-pseudo-image rule where the 48-byte header and declared length matched, bounded the decoded size, and compared each decoded member with its retained F1 extract. It also checked the retained extract against its frozen catalog hash and the applicable F2 probe fingerprint. For map members the LOD payload was stored directly; the map format's inner compression is a separate layer.

The checked archive/media `.entries` name **multisets** match the original directories, with no case-folded duplicate names; declared LOD roots fit and no member extends beyond its declared root. The `.entries` lists are **not in original directory order/case**. This is an F1 index-normalization property: use the private captured directory records for order/offset/case questions, and the retained lists only for membership. It is not an archive content mismatch. Image pixels, sprites, movies and audio payloads are outside this lane's decoded-byte signoff.
