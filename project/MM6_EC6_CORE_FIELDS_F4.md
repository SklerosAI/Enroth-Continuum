# MM6 `.ec6` core party and character fields — F4 offline progress

Status: **bounded `PART`/`CHAR` v1 codec and staging adapter, 2026-11-06; incomplete save, not wired to the game menu**.

The new `MM6CoreSaveFields` codec adds two required sections inside the existing title-tagged, CRC-checked `.ec6` envelope. Each section has its own version byte and strict length/count validation. `PART` stores gold, food, bank gold, playing-time ticks, three finite position coordinates, view yaw/pitch and active-character index. `CHAR` stores exactly four names (1–63 bytes without control bytes), sex, an MM6 class ID in 0–17, a vanilla face ID in 0–11, voice ID, level, experience, HP/SP, skill points, seven base stats, 31 MM6 skill values and 99 spell-known flags. Skill slot 30 maps to the current runtime's `SKILL_LEARNING`, following the MM6 creation path; values with Grandmaster or conflicting mastery bits are rejected. The 99 spell flags are packed into 13 bytes with zero padding required.

`decodeCoreSections` validates both payloads into a temporary value. `loadCoreFieldsBeforeMutation` decodes and checks the entire container before assigning that value to its destination. The runtime adapter checks the game title, captures these fields from a `Party`, and `stageCoreParty` applies a validated container to a **copy** of the live party; it returns the staged copy without changing the caller's party. No SaveLoad or UI path calls this adapter yet. This ordering is the foundation for a later all-family load transaction, not a complete transaction by itself.

Offline evidence: the core codec, runtime adapter and new unit source passed C++23 syntax checks using the project's compile flags, and the isolated CMake `engine_mm6_save_container` target built. A compiled standalone C++ harness round-tripped nonzero fields and verified that an invalid field with a valid container checksum and a wrong-title header each leave the destination unchanged. The new unit source covers round-trip, invalid-field staging and missing/truncated/optional/foreign section rejection, but the integrated CMake unit binary has not yet been run for this change. No MM6 game or original installation was opened.

**Completeness lock:** This payload omits condition times, resistance channels, buffs, inventory/equipment, character event/award bits, party quest/autonote bits, hirelings, shops, timers, weather, overlays, beacon images, 67 map deltas, UI thumbnail and other state listed in the [whole-save field register](MM6_SAVE_FIELD_REGISTER_F2.md). No `.ec6` writer, slot listing or load menu is enabled. Further F4 work must finish and test every required section, validate the whole save against a complete field manifest, and only then commit a staged runtime snapshot. Manual, autosave and quicksave need same-directory atomic writes with prior-save recovery; F5 must verify graphical save/quit/relaunch/load and MM7 isolation.
