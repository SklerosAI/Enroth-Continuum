# MM6 F2 gate review

Status: **frozen for F3, 2026-11-05**. This is the integration owner's decision that the research/specification phase is broad enough for the single read-only F3 original-file preflight. It is not an F3 pass, an F4 start, or a claim that MM6 runs. The reviewed pre-freeze integration commit is `2ede5285e`; the ignored `F2_FREEZE_MANIFEST.json` records the final clean source commit and report hashes after this gate decision is committed.

## Gate rule

[Plan §18.1](plan.md) requires every item, spell, skill, class, monster, map, quest/event, NPC, shop, travel route, UI screen, asset family, save field and ending path to be represented by ID/range or a private generated manifest, with confirmed/uncertain/unsupported evidence and an acceptance scenario. The F2 exit condition is **no unexamined table or map family**, plus named engine subsystems and scenarios. An explicit, source-located ambiguity may proceed to F3; an unexamined family or a falsely confirmed rule may not.

## Current decision and next check

The [pinned executable locator packet](MM6_EXECUTABLE_TABLE_LOCATORS_F2.md) gives version-sensitive MM6 source leads for spell delays, house movies and transport tables. It narrows the F3 extraction plan but supplies no original owner-executable values or running behavior; it does not close those gate limits.

The [event execution packet](MM6_EVENT_EXECUTION_SEAMS_F2.md) upgrades the 318 parser-failure count into an all-resource load constraint: 26 of 67 listed map EVT files contain rejected records, and the current loader aborts the complete event program on the first one. Its separate zero-mastery CheckSkill finding is a source/data conflict awaiting F3 corroboration. Neither observation is a live campaign result.

The [item-effect packet](MM6_ITEM_EFFECT_SEAMS_F2.md) triages all 164 remaining item-semantic rows and locates two current-source action collisions: the seven direct-use cases all use IDs above MM6's maximum, and the inherited message-scroll window guard rejects all 50 retained MM6 message-scroll IDs. It does not establish original item effects. The 67 broad special/misc roles still require exact event/door/shop and consumption joins.

The [monster-effect packet](MM6_MONSTER_EFFECT_SEAMS_F2.md) adds all-173 source-risk joins: six guide-checked male-target rows currently parse as Monk, 26 numeric multi-target preferences have no runtime reader, three weapon-break rows reach an inverted eligibility guard, and 12 inherited fixed-drop rows route to item IDs in MM6's scroll band. Exact targeting, hit/effect and loot outcomes remain for F3/F4/F5; no encounter was run.

The [creation-constants packet](MM6_CREATION_CONSTANTS_F2.md) supplies version-sensitive external addresses and shapes for MM6 starting stats/skills, HP/SP factors and skill recovery, while identifying a Cleric/no-mana inherited ID collision. Exact values, Quick Start state and trainer rules remain open. The prepared F3 PE-table helper has been exercised only against synthetic bytes and the open-gate refusal.

The [late item-guide packet](MM6_ITEM_GUIDE_CLOSURE_F2.md) classifies all 43 formerly unreviewed printed late entries by guide-evidence kind, confirms nine of ten gem-table name/value pairs with one identity dispute, and groups 400 held-item operands for 50 of 67 broad special/misc IDs. The remaining 164 item effects are not thereby original-verified. The [media-schema packet](MM6_MEDIA_SCHEMA_LEADS_F2.md) finds primary-source 44/52-byte VID/SND width leads compatible with current readers, but extensionless MM6 movie lookup and a possible VID trailer still need F3 original bytes. Twelve retained icon-frame groups are portrait candidates, not identified faces.

The [six-table role packet](MM6_UNLOADED_TABLE_ROLES_F2.md) resolves the former unexamined-family classification gap without claiming all six are active. Its source-backed BTB and weekday-news mappings are distinct from MM7 dialogue fields; `passwords` and plural `autonotes` remain explicit F3 provenance questions. The [media trigger map](MM6_MEDIA_TRIGGER_MAP_F2.md) shows static music/event-sound coverage and concrete inherited house/movie lookup conflicts. It also warns that current opcode-12 movie dispatch conflicts with the retained MM6 texture-operation shape, so those records must not be counted as proven MM6 movie triggers.

The [full manual/card review](MM6_MANUAL_CARD_FULL_REVIEW_F2.md) closes page-level owner-source coverage while adding input, social-state, options, autosave and combat-interaction acceptance. Its sword/dagger mastery descriptions conflict internally; another page misnames a spell's skill, and an XP example is not an exact threshold table. These are documented F3/F5 questions, not chosen engine rules.

The [extra-STR role packet](MM6_UNLISTED_STR_ROLES_F2.md) closes the nine-file family-classification gap. The original purpose of five extra EVT/STR pairs and the opening/win/loss text remains a source-located F3 question, with explicit F4/F5 routes. The 68 listed/global active EVT baseline does not include those extras.

The [NWC guide review](MM6_NWC_GUIDE_FULL_REVIEW_F2.md) closes the short guide's page-level gap. Fourteen named numeric mixture outputs agree with retained matrix cells, and its 20-skill chart supports the manual's Sword/Dagger table over a conflicting example. Guide-only potion effects, eleven omitted skills and one dungeon-name alias remain explicit F3/F4/F5 questions; the guide is not an executable oracle.

**Freeze decision:** the integrator reviewed all rows against [plan §18.1](plan.md), the retained private manifests and the adversarial F2 audit. No text-table, binary-table, font/media, map/delta or active event family remains wholly unexamined: the six no-literal-load tables, nine extra STR files and short NWC guide now have bounded packets. Every named subsystem has a current consumer or missing path and a specific F3/F4/F5 route. The unresolved item, spell, combat, campaign, save, service and audiovisual details above are source-located uncertainties, not confirmed original rules. Freeze F2 for **one consolidated read-only F3 preflight** under the [matrix](MM6_F3_PREFLIGHT_MATRIX.md) and [capture runbook](MM6_F3_CAPTURE_RUNBOOK.md). If original identity or a content family contradicts this snapshot, record the discrepancy privately and reopen the affected specification before F4. Do not start F4 from this decision alone.

F3 can test original archive identity, schemas, offsets, labels and spot samples in one read-only pass. It cannot by itself prove combat balance, GUI/audio playback, quest reachability, changed save-state semantics or a complete MM6 campaign. Those require F4 implementation and F5 graphical play, with the frozen MM7 app and saves left intact.
