# MM6 F4 Offline Seams

F4 implementation is underway after the [F3 original-data gate](../project/MM6_F3_GATE_REVIEW.md). The source tree has **partial offline seams**, not a playable campaign. No partial MM6 game was launched or Atlas Play action enabled for these changes.

The [headless integration policy](MM6-Headless-Integration-Policy.md) now places an MM6 game-test harness before further live joins. The runner still defaults to MM7, but explicit `--game mm6` with private data/rules paths passed a monitored null-platform startup: four MM6 game tests passed, with no focus change or on-screen window across the two-test engine smoke. It uses synthetic events and an in-memory user profile; graphical F5 remains separate.
