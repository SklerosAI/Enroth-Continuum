# MM6 unlisted STR roles — F2

Status: **retained-copy and current-source classification, 2026-11-05; original use unverified**. The existing [string probe](../scripts/mm6_probe_strings.py) pairs every one of the 67 `mapstats.txt` maps with a same-basename `.str` and `.evt`, then identifies nine additional `.str` files. This packet classifies those nine without reopening the original game installation or launching MM6. Exact names, byte hashes, counts, candidate comparisons and event opcode histograms are in ignored `local-game-data/mm6/research-2026-11-05/unlisted-str-roles-f2-private.json`. The private report fingerprints the retained string probe, map table and current consumer source.

## Source and retained-copy result

`loadMapEventsAndStrings()` in [Engine.cpp](../src/Engine/Engine.cpp) derives both resource names from the selected `mapstats.txt` filename. `initLevelStrings()` splits the selected `.str` on NUL boundaries; the event interpreter and hint renderer index that vector. A search of current `src/` found no literal load of any of the nine extra `.str` names. Since none is a listed map basename, the ordinary current map-load route does not select them. This says nothing conclusive about original-game use, alternate map names, external mods or a source path not yet identified.

| Retained group | F2 observation | Confidence and unresolved role |
| --- | --- | --- |
| Five `.str` files with same-basename `.evt` files | All five extra EVT files have bounded record frames. None has a same-basename listed map or retained base-map file. | One table-shaped `.str` file | NUL-delimited cells contain tabular NPC-style headers and records rather than map hint prose. It has no same-basename EVT or listed map. | **Candidate export/duplicate or special data resource.** Do not feed it to the map-string loader or treat it as the loaded NPC table without original provenance. |

The private report retains an individual row for **all nine** files with a candidate role, source rationale and F3/F4/F5 route. A retained entry may be unused, reserved or historic; a filename or a close text match does not prove original reachability. The original archive bytes, executable references and campaign flow have not been checked in this F2 packet.
