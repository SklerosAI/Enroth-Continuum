Gameplay recording

Capture your MM7 play session locally for later bug review, with either engine. Recording starts with Play and ends when the game closes. Game audio is not captured.

Record video

Keeps a rolling replay of the last two minutes of the display. It never grows past that unless you save a clip. Needs macOS Screen Recording permission.

Record diagnostics

Game logs, save checkpoints every 10 minutes, build identity, exit status, macOS crash reports and light CPU and memory samples. No screen access is needed.

Save the last two minutes

With video on, press ⌘⇧R while the game is running to keep the replay in a new clip folder. If the game crashes, the replay is kept automatically.
