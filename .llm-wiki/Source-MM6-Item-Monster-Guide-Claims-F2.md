# MM6 Item and Monster Guide Claims F2 Source

The [item and monster guide packet](../project/MM6_ITEM_MONSTER_GUIDE_CLAIMS_F2.md) and [queue probe](../scripts/mm6_probe_item_monster_guide_claims.py) place all 581 item IDs and 173 monster IDs in a private claim-review queue with explicit OCR match status and page locators. Nineteen guide pages and selected fields for 13 item and six monster IDs were visually checked; five printed monster treasure values disagree with the retained GOG table. Exact rows and values stay private. OCR presence and numeric triplets are locators, not per-ID effect proof. Most item/monster semantics and live combat remain open.

See also: [MM6 Combat Semantics F2 Source](Source-MM6-Combat-Semantics-F2.md), [MM6 Source and Probe Index](MM6-Source-and-Probe-Index.md), [Open Questions](Open-Questions.md).
