# MM6 Item and Monster Guide Claims F2 Source

The [item and monster guide packet](../project/MM6_ITEM_MONSTER_GUIDE_CLAIMS_F2.md) and [queue probe](../scripts/mm6_probe_item_monster_guide_claims.py) place all 581 item IDs and 173 monster IDs in a private claim-review queue. Ten guide pages were checked visually. Two selected monster treasure entries disagree with the retained GOG table; exact rows and values stay private. The guide sections and numeric triplets are locators, not per-ID effect proof. Full guide claims, item behavior, combat rules and live encounters remain open.

See also: [MM6 Combat Semantics F2 Source](Source-MM6-Combat-Semantics-F2.md), [MM6 Source and Probe Index](MM6-Source-and-Probe-Index.md), [Open Questions](Open-Questions.md).
