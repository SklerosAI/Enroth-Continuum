# MM6 F4 Offline Seams

F4 implementation is underway after the [F3 original-data gate](../project/MM6_F3_GATE_REVIEW.md). The source tree has **partial offline seams**, not a playable campaign. No partial MM6 game was launched or Atlas Play action enabled for these changes.

Its default Mac data lookup targets the private MM6 app folder; MM7's target and bundle identity still build. | Finish title-specific rules and `.ec6` saves, then F5 play before Atlas stages this helper. The build target itself is not a working installation. |

The integrated native `MM6.app`, MM7 `OpenEnroth.app` and unit targets built on this Mac, and the offline suite passed 123 tests. These cover event framing and selected guarded effects, title-specific class/item/autonote variable checks, indoor/outdoor wire readers and retained projections, `.ec6` field codecs and sixteen-section assembly, private transport/spell, healing, timed-cure and combat-buff rules, the 841-cell potion matrix and guarded consumable path, spell-item IDs and school prerequisites, monster descriptor bounds, hireling/NPC lookup and item-icon bounds, F3-verified private map-source/base validation and directory order. The event fixture includes all 68 active retained EVT resources, the indoor fixture checks all 52 pairs, and the outdoor fixture checks all 15 from ignored local data. The known-save validator exercised all 67 retained base/delta pairs and negative rejection cases. The runner also passed F3-matched spell-item, actor-descriptor, item-footprint, class/school and private 67-name map-manifest checks. The general non-MM6 unit suite passed 438/438 from the same build; creation exporter tests passed separately. Original game data and exact per-ID reports remain ignored under `local-game-data/`.

After building the unit target, run [the offline suite](../scripts/mm6_f4_run_offline_tests.py) against ignored retained fixtures. Use a separate worktree for concurrent code; the protected MM7 and reserved MM8 checkouts are not implementation scratch space. A parser pass, successful build or synthetic fixture does not satisfy F5.
