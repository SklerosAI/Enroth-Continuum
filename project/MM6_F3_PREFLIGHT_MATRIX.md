# MM6 consolidated original-file preflight matrix

Status: **draft for F2 review, 2026-11-05; F3 has not run**. This is the one planned read-only check of the owner's original MM6 installation after the F2 source/guide specification is broad enough. It lists what the preflight must confirm, what may remain an explicitly named semantic ambiguity, and what must be retained privately. It is not permission to mark F2 complete or begin F4 from inventory alone.

## Entry and output contract

1. Freeze the authoritative [implementation checklist](MM6_IMPLEMENTATION_CHECKLIST.md), focused F2 specs, current source commit, and retained-reference report hashes. Every F2 domain needs a parser/consumer map and an acceptance scenario or explicit unresolved item. Once the gate is explicitly frozen and the tracked tree is clean, `scripts/mm6_f2_freeze_manifest.py` records tracked-source and ignored-derived-report SHA-256 values in an ignored private manifest. The script has not been run and does not open the original install.
2. Identify the owner's original install and capture file identity, size and SHA-256 for each input. Read originals without modification. Make one consolidated pass over archives, executable and media directories; write a dated reconciliation report and any decoded per-ID evidence only under ignored `local-game-data/mm6/`.
   The prepared `scripts/mm6_f3_identity_preflight.py` checks the eight F1-ledger archive/media/executable hashes against that original installation and writes an ignored report. It refuses to read originals until the F2 gate, ignored freeze manifest and clean source SHA agree. It has **not** been run on originals; identity matching alone does not complete the content/schema rows below.
3. Compare originals with the retained extracted copies and all tracked probe results. If content differs, stop the implementation lock, explain which report is stale, and regenerate it from the fresh local snapshot. Do not quietly merge discrepant copies.
4. For every family below, record **expected from F2**, **observed original**, **difference**, **resolution or known ambiguity**, source hash/locator, and the F4/F5 acceptance scenario. Zero unexplained content gaps is the F3 exit condition; unknown gameplay semantics remain listed with a specific implementation and test plan.
5. Keep original files, game text, guide passages, raw table rows, exact per-ID mappings, saves, screenshots and local logs out of Git. The public checklist and `.llm-wiki/` receive only aggregate conclusions and source/probe pointers. Preserve the MM7 worktree, helper and profile; do not install an MM6 build during F3.
