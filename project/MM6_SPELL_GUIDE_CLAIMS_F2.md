# MM6 spell-guide claim audit: identity and selected scans

Status: **partial F2 claim reconciliation, 2026-11-05**. This packet joins all 99 retained MM6 spell IDs to the owner's Prima guide spell headings and records a full spell-section page-image pass for identity, base cost, target and damage type. It does not resolve all spell effects, reopen original archives, run MM6, or close F2. Exact per-ID joins and observations remain under ignored `local-game-data/mm6/research-2026-11-05/`.

## Reproducible coverage

`scripts/mm6_probe_spell_guide_claims.py` reads the already retained Prima PDF, its indexed hash, and `spell-effect-probe.json`. It writes an ignored `spell-guide-claims-probe.json` with a guide PDF page and current engine comparison for each of the **99 spell IDs**. All 99 have a guide heading: 98 normalized names agree with the retained table, and one OCR heading was corrected from a directly rendered page. One decorative glyph also required a scan-checked heading locator. This is **identity and locator coverage**, not all 99 spell mechanics checked.

All **56 PDF pages** in the spell section were rendered and inspected, including a continuation page after the last Spirit heading. The ignored `spell-guide-claims-matrix-private.json` now records each of the **99 entries** with guide page, base cost, target class and damage channel alongside the retained MM6 cost and current inherited static data/case. The 99 visually checked guide **base** casting costs agree with the retained MM6 table; **22** differ from the inherited static MM7 base cost at the same numeric ID. The existing spell-effect probe's 27 cost-triple differences also include mastery-rank changes, so the two counts have different scopes. This pass does not establish recovery time or quantitative effects for all ranks. The scans corroborate that matching numeric IDs and some matching labels can still route to an unrelated inherited effect. Private notes record exact IDs, values and page locators; no guide passage is copied here.

The visual pass found two guide entries that omit an Expert cost change present in the retained table, one entry whose prose and damage-result cell disagree, and one whose prose describes an object target while its target cell names the party. A focused **17-entry** rank-clause transcription found two additional guide-versus-retained-table disagreements: one Normal duration and one item-to-gold Expert/Master yield. These are **guide/table or guide-internal ambiguities**, not facts to hardcode. The guide explicitly leaves the final Dark spell's rank effects unknown. Each case is identified in the ignored private matrix/notes for the consolidated F3 original-data comparison and later live validation.

The scan establishes the following **PDF page starts** for the nine schools: Fire 100, Air 106, Water 112, Earth 118, Spirit 124, Mind 131, Body 137, Light 143, Dark 149. These correct the approximate printed-page ranges in the earlier [spell effect audit](MM6_SPELL_EFFECT_F2.md), which end one page early for several later schools. Use the per-ID private PDF locator instead of the earlier range when reviewing a claim.

The [spell effect audit](MM6_SPELL_EFFECT_F2.md) already documents scroll/book, event, monster and targeting collisions. This new locator lets F2 reviewers tie each such collision to its actual guide page.

The focused rank transcription covers 17 entries; **82 still need normalized Normal/Expert/Master clause transcription**. All 99 need current C++ effect-consumer comparison for duration, damage formula, restrictions, recovery and failure behavior. Target and damage-type classifications in the matrix identify candidate behavior, not verified runtime semantics. F3 can confirm the original shipped table and executable constants in the planned single read-only pass, including the named guide ambiguities.
