# MM6 Campaign F2 Closure Source

The [campaign closure packet](../project/MM6_CAMPAIGN_F2_CLOSURE.md) and tracked [route probe](../scripts/mm6_probe_campaign_routes.py) join retained event, dialogue, house, transport and quest-reference indexes. These are static source links. Guide-keyword milestones are candidate leads, not control-flow or quest-reachability proofs; the current MM6 map session has not run.

The retained transport table has 21 typed houses; six stable IDs lie outside the inherited MM7 route array. A loaded MM6 `trans.txt` supplies display descriptions in current C++, not destination schedules. Another 74 NPC-topic references have global event functions but fall in an inherited teacher-special range whose handler precedes global event dispatch. Two active Hive pseudo-house instructions enter an MM7 game-over/certificate and Harmondale respawn path by current source control flow. These are title-routing risks and implementation obligations, not observed crashes, reachable quests or proof of the original MM6 ending. Exact record IDs, event offsets and dialogue remain private.
