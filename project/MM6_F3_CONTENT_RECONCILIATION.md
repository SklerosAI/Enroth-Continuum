# MM6 F3 original content reconciliation — tables, maps and events

Status: **read-only F3 content identity and structural signoff for the families below, 2026-11-05**. This packet does not complete the full [F3 matrix](MM6_F3_PREFLIGHT_MATRIX.md), begin F4, or claim playable MM6. Original GOG files were read only from the owner's local installation; exact filenames, member offsets, hashes, decoded bytes and per-file decisions remain Git ignored in `local-game-data/mm6/research-2026-11-05/F3_CONTENT_RECONCILIATION_2026-11-05.json` and `F3_CONTENT_SCHEMA_SIGNOFF_2026-11-05.json`. The private reproduction script there has the source method. No MM6 process was launched or MM7/MM8 path changed.

## Method and provenance

The gated F3 identity report matched all **eight** core archive/media/executable files and **15** soundtrack tracks to the frozen F1 snapshot; the bounded capture reported no directory/name/size/hash discrepancy. This lane reread only the original `icons.lod` and `Games.lod` during the same F3 session, rechecked their whole-file hashes against the capture/F1 ledgers, then extracted selected members through their captured bounded offsets. It applied the current fork's MM6 compressed-pseudo-image rule where the 48-byte header and declared length matched, bounded the decoded size, and compared each decoded member byte for byte with its retained F1 extract. It also checked the retained extract against its frozen catalog hash and the applicable F2 probe fingerprint. For map members the LOD payload was stored directly; the map format's inner compression is a separate layer.

The four LOD directory counts remain **2,703 icons, 134 Games, 1,958 bitmaps and 4,314 sprites**. All seven archive/media retained `.entries` name **multisets** match the original directories, with no case-folded duplicate names; all four LOD declared roots fit and no member extends beyond its declared root. The `.entries` lists are **not in original directory order/case**. This is an F1 index-normalization property: use the captured original directory records for order/offset/case questions, and the retained lists only for membership. It is not an archive content mismatch. Image pixels, sprites, movies and audio payloads are outside this lane's decoded-byte signoff.
