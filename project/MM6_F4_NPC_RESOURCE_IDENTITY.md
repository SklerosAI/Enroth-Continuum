# MM6 v2 NPC resource identity before publication

Status: **read-only detached prepublication plan**. The normal MM6 SaveLoad/menu and Atlas Play remain guarded. No private NPC table text or generated result is stored here.

`NPCStats::InitializeMm6()` reads four static `NPCStats` tables through `InitializeMm6Static()` and separately fills process-wide `pNPCTopics` from `npctext.txt` and `npctopic.txt` (`src/Engine/Tables/NPCTable.cpp`). The v2 `RESC` section carries mutable 501 NPC rows, 51 group words and an active count. `stageRawWorldAndVisuals()` overlays these onto a freshly parsed `NpcStaticBaseline`, so loading RESC alone does not establish the live static name pool, profession prices/text/weights, news phrases, original NPC rows or topic text.

`inspectNpcResourceIdentity()` reads the six source resources through the caller's loaded `ResourceManager` and independently reparses the four static tables. It compares the fresh image with the typed baseline, staged NPC owner and live NPC static tables: original rows, unique/random names, news phrases, profession text/prices and MM6 chance weights. It separately encodes staged mutable rows/groups and requires exact equality with RESC. It reconstructs the 789-entry topic/text array using the MM6 `InitializeMm6()` index rules and compares every entry with the live process array. A mismatch rejects before any assignment or RNG draw. The direct-input overload lets synthetic tests exercise the same logic without private assets. The `ResourceManager` has no title getter; this check establishes equality with the resources supplied by the title-selected caller, not an independent archive signature.

The returned plan still refuses NPC publication. `Engine::_461103_load_level_sub` resets `uNewlNPCBufPos`, then calls `InitializeAdditionalNPCs()` for eligible rebuilt actors and assigns their `npcId` values after map reconstruction. The checker reports `GeneratedNpcIdentityAfterMapLoad` and `GameRngStateUnrepresented`; it also flags a preexisting generated-NPC cursor or nonfresh mispronounced-name cache. A later post-map identity check must compare actor `npcId` links with the resulting generated entries before dialogue or controls resume. Restoring the saved RNG stream or defining deterministic regeneration requires a separate source-backed policy.

The synthetic focused tests cover a matching static/topic/RESC image, explicit generated/RNG blockers, stale generated cursor, and mismatches in topic text, profession price, mutable RESC and title. They do not prove graphical dialogue or a complete campaign reload. The checker must be called from a fresh title-locked child before a future publication transaction; it is not yet wired into the current v2 admission coordinator.
