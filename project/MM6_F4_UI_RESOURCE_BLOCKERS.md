This packet covers the inherited `SetUserInterface`, `UI_Create` and the immediate `Engine::DrawGUI` consumers. It uses source call order, the retained private MM6 icon set and the original manual's main adventure screen (pages 30–31). No proprietary image, inventory or manual text is tracked here. The MM7 path is unchanged.

The manual places an automap, compass, day/night indicator, follower window, four books and portrait health/spell bars around the adventure view. The inherited code already has title-local MM6 frame pieces (`border1.pcx` through `border4`), footer, compass/zoom controls, 8 map arrows, baked book/action hit boxes and native health/mana bars. These headless resource checks have passed in the existing MM6 suite. The retained `tap1`–`tap4` panels are each 172×142. It draws the selected panel at `(468,0)` after automap work and skips palette index zero. The four LOD transparency flags are false despite their index-zero aperture pixels. MM6 now forces index-zero masking for these four icons, skips the inherited `ib-autmask-*` requests and draws its selected panel at the existing post-automap point. MM7 retains its original alignment-specific request and draw.
