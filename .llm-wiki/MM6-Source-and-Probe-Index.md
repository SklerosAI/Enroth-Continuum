# MM6 Source and Probe Index

This index directs agents to the current public specifications and reproducible offline probes; detailed outputs and original game material stay in the ignored private companion.

## Authority before a probe

- [Plan §18.1](../project/plan.md) defines F0–F6 gates and the one deliberate F3 original-data preflight.
- [MM6 implementation checklist](../project/MM6_IMPLEMENTATION_CHECKLIST.md) is the public coverage and gap register; its checked research rows are not playable-rule claims.
- [F2 gate review](../project/MM6_F2_GATE_REVIEW.md) records the frozen source baseline for the consolidated original-file pass.
- [F3 gate review](../project/MM6_F3_GATE_REVIEW.md) accepts the source-data reconciliation for offline F4, with named F4/F5 obligations. [F3 preflight matrix](../project/MM6_F3_PREFLIGHT_MATRIX.md) and [F3 wiki synthesis](MM6-F3-Read-Only-Preflight.md) give the family routes. This is not a playable-game result.
- [F3 capture runbook](../project/MM6_F3_CAPTURE_RUNBOOK.md), [identity checker](../scripts/mm6_f3_identity_preflight.py) and [capture helper](../scripts/mm6_f3_capture_snapshot.py) ran on the frozen inputs: 23/23 original identities matched and bounded directories passed. Their reports are ignored locally.
- [MM6 executable table locators F2](../project/MM6_EXECUTABLE_TABLE_LOCATORS_F2.md) supplied pinned layout leads. The [F3 PE-table helper](../scripts/mm6_f3_pe_tables.py) read the identity-matched executable; the [PE reconciliation](../project/MM6_F3_PE_RECONCILIATION.md) and [code-consumer follow-up](../project/MM6_F3_EXECUTABLE_FOLLOWUP.md) provide the interpreted results and limits.
- [F3 content reconciliation](../project/MM6_F3_CONTENT_RECONCILIATION.md) byte-matched 348 original members; [media reconciliation](../project/MM6_F3_MEDIA_RECONCILIATION.md) checked VID/SND/music structures; [portrait/voice](../project/MM6_F3_PORTRAIT_VOICE_RECONCILIATION.md) checked 636 original face pixels; [actor-ID reconciliation](../project/MM6_F3_ACTOR_ID_RECONCILIATION.md) confirmed one baseline ID 173 reference.
- [F4 offline build graph](../project/MM6_F4_BUILD_GRAPH.md) is the implementation dependency and acceptance plan. F4 work is allowed; no F5 graphical pass or MM6 Atlas Play action exists.
- [F2 freeze manifest helper](../scripts/mm6_f2_freeze_manifest.py) fingerprints tracked specs and ignored derived JSON/Markdown/text/TSV/CSV/entry-list reports and guide PDFs after an explicit F2 freeze and a clean tracked tree. It includes F1 identity ledgers and private page/claim ledgers and never reads the original install.
- The guarded F3 helpers verified the F2 gate, frozen source SHA and report hashes before original reads and refused report overwrite. Later targeted reads were source-hash checked within the same session. The private v2 PE join supersedes its first version; use only the corrected report.
- [Local status](../project/LOCAL_STATUS.md) records observed Mac behavior and its limits.
- [OpenEnroth credit](../CREDITS.md) and [upstream relationship](../project/UPSTREAM.md) govern attribution.

Run each script only with its documented local ignored reference and output arguments. The scripts and specs can change; record their Git SHA and the private report's source fingerprints before trusting a result. A stale report must be regenerated or explicitly marked stale. Never stage a private report, raw table, decoded archive, guide text, save, screenshot or trace. A new probe belongs in this index only after its tracked version and output-boundary behavior have been reviewed.

For exact proprietary-derived rows or uncertainty decisions, open `local-game-data/private-wiki/INDEX.md` locally and follow its report registry. That path is ignored, local only, and **not backed up by Git**; protect it with an owner-approved local backup. It is not a GitHub Wiki or public source.
