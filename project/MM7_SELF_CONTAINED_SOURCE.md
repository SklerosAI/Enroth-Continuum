# MM7 source autonomy in SklerosAI

Status: **migration underway; fail-closed local-only configure gate and twelve repo-owned dependencies added** (2026-11-07). The [build-input packet](MM7_SELF_CONTAINED_BUILD_INVENTORY.md) records the original cached artifacts, 23 former gitlinks, seven nested fetched sources, provenance gaps and a phased migration. Pinned `generator`, `fast_float`, `magic_enum`, `mio`, `small_vector`, `cmrc`, `cli11`, `fmt`, `spdlog`, `sol2`, GoogleTest and `gtest_parallel` are now tracked here, leaving 11 gitlinks. The owner wants the Mac MM7 engine and every required non-system build input available from the SklerosAI repository itself. A clean offline clone still cannot build today.

## Current boundary

The `MM7` target and Atlas helper are compiled from Enroth Continuum's own forked source. Atlas stages an explicitly supplied, title-locked `MM7.app`; it does not download or run an OpenEnroth release binary. OpenEnroth's Git history, LGPL license, notices and contributor credit remain part of the fork.

A clean Mac build is not yet self-contained. The normal configure path can still download a versioned archive from `OpenEnroth/OpenEnroth_Dependencies`, update 11 externally hosted Git submodules, and fetch nested cpptrace/ztd.text sources. Cached local dependencies hide those requirements on this Mac. Twelve pinned, license-preserving third-party snapshots are now repository-owned; standalone network-disconnected checks and the cached-input Mac MM7 target passed. GoogleTest and `gtest_parallel` are optional test inputs, not MM7 app runtime libraries. The new opt-in `EC_LOCAL_ONLY_CONFIGURE=ON` path blocks the remaining configure-time network routes, defaults prebuilt dependencies off and fails with named missing repository-owned inputs; it deliberately refuses even when source directories are present until local source-build recipes are connected. A fresh arm64 AppleClang configure reached that named refusal without a download. It is a migration scaffold, not a successful offline build. The current `launcher/AtlasApp.swift` also defaults MM7 data and saves to legacy `OpenEnroth` locations; its saved-folder and character-transfer actions use that same legacy profile. The upstream Git remote is optional for reviewed synchronization; it is not a runtime input.

## Migration gate

1. Freeze the working MM7 source revision, installed helper, save/profile backup and build hashes. Keep Atlas pointed at the known-good helper until the replacement passes launch and save/load checks.
2. Record each Mac MM7 build input, exact revision/hash, license, current fetch path, size and whether it is required at runtime. Keep original Might & Magic game data and saves outside Git.
3. Replace OpenEnroth-hosted prebuilt dependency downloads with reproducible source builds from pinned, license-preserving inputs held in this repository. Replace required Mac-build submodule/fetch-at-configure dependencies with repository-owned source snapshots. Do not remove upstream copyright files or flatten authorship without a traceable provenance record.
4. The opt-in local-only configure gate now fails clearly on missing inputs and refuses cached/system-library substitution. Connect pinned repository-owned build recipes, then produce arm64 `MM7.app` and stage Atlas from a clean SklerosAI checkout while offline, using the installed Apple toolchain/SDK.
5. Check the app's title lock, notices and library links, then launch MM7 through Atlas, load an existing save, save again, quit and reload. Confirm the MM6/MM8 sibling slots and private profiles remain untouched.
6. Give Atlas an explicit MM7 data root and profile under the private `Enroth Continuum` local directories, including its save browser and transfer adapter. Copy and hash-check the owner's existing data and saves locally before changing defaults; retain the legacy locations as a rollback source until the new launch/save/reload path passes. Do not put proprietary files or saves in Git.
7. Audit the installed app's user-facing name, bundle metadata, Atlas text, CLI defaults, configuration, caches, logs and save paths. Present the finished Mac helper as Enroth Continuum/MM7 and migrate inherited OpenEnroth runtime locations without losing existing saves. Keep historical OpenEnroth names in attribution and provenance; internal source identifiers can be renamed separately when safe.

The completion claim means a fresh clone can configure, compile and package the **Mac MM7 engine and its required non-system build inputs** with networking disabled, without an OpenEnroth checkout, release archive, submodule origin or build-time URL.
