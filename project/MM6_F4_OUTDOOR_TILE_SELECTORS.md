# MM6 F4 outdoor tile selectors

Status: **MM6-only selector reconstruction linked; unchanged-season identity staged; terrain appearance remains open** (2026-11-06).

The earlier offscreen diagnosis that the original first outdoor map contains 209 tile-zero cells is superseded. A read-only decode of the retained map found no literal local tile ID zero in its used 127×127 terrain grid. The 209 `pending` textures came from inherited reconstruction: it ignored the map's four serialized base tile IDs, converted their tile-set labels through an MM7 enum that collapses MM6 terrain and road types to dirt, then added local offsets to that substituted base. The original local IDs were valid; the reconstruction was not faithful.

The staged original MM6 executable was rehashed against the accepted F3 SHA-256 before inspection. Its terrain accessors at `0x46e1dd` and `0x46e225` read the signed 16-bit base field of a selected four-byte terrain record, then add the local tile offset. This establishes the base field as the map's intended global tile index source. Exact executable bytes and private map records remain local and ignored.

`OutdoorLocation::Load` now passes the title to outdoor reconstruction. MM6 uses each serialized base directly, requiring a nonzero 36-tile span within the loaded tile table and checking every reconstructed tile ID before storage. MM7 retains its existing base lookup through the normalized tileset. The change does not alter tile-table contents or substitute a new bitmap for `pending`.

A read-only replay of all **15** retained MM6 outdoor maps checked **241,935** used terrain cells against the retained tile-table size and found **zero** blank or `pending` textures with serialized bases. For the first map, the inherited mapping produced **209** `pending` cells and the corrected pre-season mapping produced **zero**. A headless GameTest stages these comparisons, verifies a separate neutral summer-season no-`pending` result, rejects zero/out-of-range MM6 selectors, and checks that the MM7 branch ignores those MM6 selector fields. Its first linked run exhausted the game-test thread stack because it placed multiple large outdoor snapshots and terrains there; moving those test fixtures to owned heap objects made the monitored test pass **1/1** across 353 samples with no on-screen window or focus change. The MM7 headless control passed **1/1** across 48 samples.

The inherited seasonal path was another fidelity gap. A read-only model of its variant remap, before transition recalculation, replaced **1,230** first-map cells at neutral summer month because the shared `TileData` tileset enum collapses MM6-only terrain and road types to generic dirt. The identity-matched MM6 executable's terrain accessor reads the authored tile base without a month branch, but its full season handling elsewhere remains unproved. The current engine's `tilesetForSeason` changes only grass; for an MM6 tile whose normalized tileset is unchanged, seasonal conversion now retains its authored global tile ID. Its shared transition pass can also rewrite an unchanged tile, so the MM6 branch restores those IDs after the pass. MM7 still performs its original transform and transition recalculation. This establishes a narrow identity rule, not a complete MM6 season model.

The focused headless test now requires exact first-map and all-15-map identity after a neutral summer projection, retains MM6-only terrain and road IDs in winter, and observes a changed grass ID. It also exercises the untouched MM7 season route. Linked execution of the new seasonal assertions and a fresh hidden OpenGL recapture remain pending. The preceding selector-only hidden capture passed **1/1** over 117 samples without window/focus change and removed the cyan/red placeholder, but much of the ground rendered black because MM6 land and water were allocated to the same texture unit. Winter/spring grass appearance, shoreline transitions, walking sounds and the complete original seasonal policy remain separate acceptance gates. A future MM6 tile schema should preserve raw terrain and variant identities alongside normalized runtime classification before broader transition or season reconstruction.

The map still relies on the existing out-of-range local-tile sentinel mapping; this packet establishes only the selector base for valid mapped cells. Normal save/chest guards remain closed.
