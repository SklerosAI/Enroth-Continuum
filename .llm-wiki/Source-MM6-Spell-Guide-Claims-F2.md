# MM6 Spell Guide Claims F2 Source

The [spell guide packet](../project/MM6_SPELL_GUIDE_CLAIMS_F2.md) and [probe](../scripts/mm6_probe_spell_guide_claims.py) give all 99 retained MM6 spell IDs a guide heading locator. Seventeen entries were directly checked on eleven rendered pages: all selected guide costs matched the retained MM6 table, while four differed from inherited MM7 static costs. Eighty-two entries and all 99 detailed effects still need direct claim review. Exact values and page images remain ignored locally.
