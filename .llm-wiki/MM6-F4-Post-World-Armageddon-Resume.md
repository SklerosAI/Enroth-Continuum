# MM6 F4 Post-World Armageddon Resume

The [source-backed packet](../project/MM6_F4_POST_WORLD_ARMAGEDDON_RESUME.md)
defines a detached plan for restoring a saved active Armageddon timer after
world preparation clears it.

The plan checks the exact `RCVR` clock/damage/force tuple, zero post-world
timer and an outdoor map for an active effect. A separate read-only check
requires the final Party to contain the planned timer before first input.
The helper never assigns a live Party. Source and test translation units pass
AppleClang syntax checks; linked integration and a v2 first-frame scenario
are pending. Spell sprites, actor panic and RNG remain separate gates.

See also: [Raw Child Publication Gate](MM6-F4-Raw-Child-Publication-Gate.md), [Recovery and Calendar](MM6-F4-Recovery-and-Calendar.md).
