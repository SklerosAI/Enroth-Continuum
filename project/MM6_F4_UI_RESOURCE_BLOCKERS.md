The party-creation `aframe1` request has also been routed to the same MM6 selected-portrait sprite. Retained F3 evidence places the 69×91 oval in `sprites.lod`; the accepted executable looks it up through its sprite-frame table. The MM6 table records palette ID **2**, previously misread as zero under the inherited MM7 layout. The generic sprite decoder stores palette indices in the red channel for 3D rendering. The MM6-only UI cache resolves those indices through palette 2, preserving zero alpha, and `releaseAllTextures` releases its texture with the renderer. This removes the wrong-archive icon request; its final appearance still needs a rendered comparison.
